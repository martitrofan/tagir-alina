# Тагир & Алина — сайт-приглашение

Мобильное одностраничное приглашение на свадьбу 13 августа 2026.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

Публикация: push в `master` → GitHub Actions → GitHub Pages.

Исходные фото лежат в `photos/` (не в git). Веб-версии — в `public/images/`.
